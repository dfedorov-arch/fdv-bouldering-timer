## Новое по сравнению с 2.3.2

- Добавлен резервный сервер: синхронизация состояния, переключение экранов после 2 секунд недоступности основного и автоматический возврат при восстановлении в течение 20 секунд. Позже резерв сохраняет управление, а вернувшийся сервер становится резервным. Диагностика объединяет браузеры обоих серверов.
- Добавлен серверный звук для Windows, Linux и macOS. После включения воспроизведение поддерживает сам сервер, включая работу при закрытом браузере. Для каждого экрана доступны выбор канала и поправка звука; при отказе серверного канала предусмотрены переход на браузер и автоматическое восстановление выбранного канала.
- Расширена подготовка звука: тихий прогрев перед сигналами и при нажатии «Старт», повторный прогрев во время ожидания ручного старта Финала. Добавлена настройка поддержания активности Bluetooth-колонки.
- Добавлены PIN управления, ограниченное управление с дополнительных браузеров (CTRL) и защищённые сессии; обмен между связанными серверами шифруется. Команды экранов получили подтверждение выполнения в диагностике.
- Добавлено растягивание цифр по высоте отдельно для каждого экрана, включая совместимые Legacy-браузеры. В `params.txt` задаются включение по умолчанию и максимальный процент; стандартный предел — 200%. Двоеточие современного экрана сохраняет пропорции.
- Обновлены лаунчеры: единые кнопки и оформление, переключение RU/EN, скрытие окна с сохранением работающего сервера, создание HTTPS-сертификата, проверка новых версий и переход на сайт проекта. Строка состояния показывает роль сервера, адрес пары и потерю связи.
- Обновлены блок настроек, диагностика браузеров и руководство со скриншотами.
- Исправлены незначительные ошибки в работе звука, резервирования и интерфейса.

Доступны установщики и portable-пакеты для Windows, Linux и macOS, отдельные архивы Windows 7/8 и Android APK. Версия релиза — **3.0.0**, сборка таймера — **454**. После обновления перезапустите сервер и обновите подключённые страницы.

## New since 2.3.2

- Added a standby server with state synchronization, display failover after 2 seconds without primary contact, and automatic return if the primary recovers within 20 seconds. After that window the standby retains control and the returning server becomes standby. Diagnostics combine browsers from both servers.
- Added server audio for Windows, Linux and macOS. Once enabled, the server maintains playback, including when the browser is closed. Each display has channel selection and audio correction; server-channel failure supports browser fallback and automatic restoration of the selected channel.
- Expanded audio preparation with quiet warmups before signals and on Start, and repeated warmups while Final waits for manual start. Added a Bluetooth-speaker keep-awake setting.
- Added a control PIN, limited control from additional browsers (CTRL), and protected sessions; paired-server traffic is encrypted. Display commands now show execution acknowledgements in diagnostics.
- Added per-display vertical digit stretching, including compatible Legacy browsers. `params.txt` controls the default and maximum percentage, with a default limit of 200%. The modern display's colon retains its proportions.
- Updated launchers with consistent controls and styling, RU/EN switching, hide-on-close while keeping the server running, HTTPS certificate creation, update notifications and a project-site button. The status line shows the server role, peer address and connection loss.
- Updated settings layout, browser diagnostics and the illustrated guide.
- Minor bugs fixed in audio, failover and the interface.

Installers and portable packages are available for Windows, Linux and macOS, along with separate Windows 7/8 archives and an Android APK. Release version: **3.0.0**; timer build: **454**. Restart the server and reload connected pages after upgrading.
