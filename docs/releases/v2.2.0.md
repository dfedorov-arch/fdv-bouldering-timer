## Изменения

- Исправлено периодическое возвращение старого количества трасс при работающем таймере. Вводимое значение сохраняется при синхронизации; изменение применяется после подтверждения ввода, а последовательные изменения отправляются по порядку.
- Изменение количества трасс сохраняется отдельно для выбранного списка. Проверка версии списка защищает от перезаписи более новых изменений; при ошибке сохранения введённое значение сохраняется для повторной попытки.
- Пройденные трассы обозначаются сине-фиолетовыми ромбами (`#48488C`). Цвета подготовки, активного участника, пройденной, приостановленной и остановленной трассы настраиваются в `params.txt`: `list_ready_color`, `list_active_color`, `list_done_color`, `list_paused_color`, `list_stopped_color`. Настройки работают на обычных и Legacy-экранах.
- Подсказка имени автора содержит Email и Telegram. Обновлены подпись руководства, описание настроек, архитектурная документация, тесты и иллюстрации.

Сборка приложения: **405**. Для применения обновления перезапустите сервер после установки.

## Файлы для установки

- Windows x64: MSI и portable ZIP.
- macOS: PKG и portable TAR.GZ для Intel (x64) и Apple Silicon (ARM64).
- Debian/Ubuntu Linux: DEB и portable TAR.GZ для x64 и ARM64.
- Android: подписанный APK **FDV Bouldering Timer**, только автономная версия для одного устройства — без встроенного сервера, сетевых экранов и синхронизации. Используется прежний ключ подписи для обновления приложения.
- Любая ОС с браузером: один автономный HTML-файл. Веб-версия также доступна на [GitHub Pages](https://dfedorov-arch.github.io/fdv-bouldering-timer/standalone.html).

Desktop-пакеты включают Node.js 24.17.0 LTS, темы, шрифты, звуковые профили и руководство. Установленные версии используют пользовательский каталог состояния; portable-версии сохраняют состояние рядом с программой, с резервным пользовательским каталогом при запрете записи. `SHA256SUMS.txt` содержит контрольные суммы всех пакетов релиза.

## Changes / English

- Fixed intermittent route-count rollback while the timer is running. Synchronization preserves the input draft; confirmed edits are applied in order.
- Route-count changes are saved separately for the selected start list. Revision checks prevent overwriting newer list changes, and failed saves retain the input for retry.
- Completed routes use blue-purple diamonds (`#48488C`). Configure preparing, active, completed, paused, and stopped marker colors in `params.txt` with `list_ready_color`, `list_active_color`, `list_done_color`, `list_paused_color`, and `list_stopped_color`. Both modern and Legacy displays support these settings.
- The author tooltip now includes Email and Telegram. Updated the guide footer, settings reference, architecture documentation, tests, and screenshots.

Application build: **405**. Restart the server after upgrading.
