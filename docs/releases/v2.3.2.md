## Единое подтверждение смены формата Финала

Точечный стабильный выпуск на основе v2.3.1. Остальные новые функции develop в него не включены.

- После «Стоп» переход из начатого Финала в Классику, Фестиваль или переключение «Старый / Новый» используют один вопрос: «Вы уверены, что хотите завершить \"Финал\"?».
- Отмена сохраняет формат, прогресс и список, возвращая прежнее положение переключателя. Подтверждение завершает текущий Финал и сбрасывает его счётчик: новый Финал начинается с первой ротации.
- При смене «Старый / Новый» сохраняются длительность и количество ротаций отдыха. Для ещё не начатого Финала подтверждение не требуется.
- Во время работы, на паузе, после естественного окончания или в ожидании ручного старта сначала требуется нажать «Стоп». Дополнительные экраны не получают права менять формат.
- Добавлены проверки подтверждения и отмены на двух экранах, обеих языковых версий, автономного HTML и HTML для Android. Исправление START из v2.3.1 сохранено и повторно проверено.

Сборка приложения: **440**. После установки перезапустите сервер и обновите все подключённые страницы; они должны показывать сборку 440. Формат меняйте только если действительно хотите завершить текущий Финал.

Заметка: расследование сообщения о полном отсутствии всех звуков на отдельных устройствах остаётся отдельной задачей. Этот выпуск не заявляет исправления пока не воспроизведённой причины полной тишины.

## Unified Final format-change confirmation

A narrowly scoped stable update based on v2.3.1, without other newer develop features.

- After Stop, leaving a progressed Final for Classic, Festival, or changing Old / New uses the same question: “Are you sure you want to end \"Final\"?”.
- Cancel preserves format, progress and the list, restoring the previous radio selection. Confirmation ends the current Final and resets its counter, so a new Final begins at rotation one.
- Old / New changes retain the duration and rest-rotation count. An unstarted Final needs no confirmation.
- Running, paused, naturally completed and manual-start-waiting attempts still require Stop first. Other displays do not gain format-changing permission.
- Added two-screen confirmation/cancellation coverage, both languages, standalone HTML and Android HTML. The v2.3.1 START fix is retained and rechecked.

Application build: **440**. Restart the server and reload every connected timer page after upgrading; pages should show build 440. Change formats only when you intend to end the current Final.

Reports of complete silence on some devices remain a separate investigation; this release does not claim a fix for an unverified cause of all sounds being absent.
