## Новое в 3.0.1

- Добавлено окно настроек в лаунчерах Windows, Linux и macOS: параметры `params.txt` можно редактировать через кнопку с шестерёнкой. После сохранения изменений можно сразу перезапустить сервер; если значения не изменились, окно просто закрывается.
- Подготовка запуска сервера выполняется в фоне, сохраняя отзывчивость лаунчера. При превышении времени ожидания запуск можно повторить.
- Исправлены незначительные ошибки в работе звука и лаунчера.

Версия релиза — **3.0.1**, сборка таймера — **455**. После обновления перезапустите сервер и обновите подключённые страницы.

## New in 3.0.1

- Added a settings window to the Windows, Linux and macOS launchers: edit `params.txt` through the gear button. After saving changes, you can restart the server immediately; if values are unchanged, the window simply closes.
- Server startup preparation runs in the background, keeping the launcher responsive. Startup can be retried after a timeout.
- Minor bugs fixed in audio and the launcher.

Release version: **3.0.1**; timer build: **455**. Restart the server and reload connected pages after upgrading.
