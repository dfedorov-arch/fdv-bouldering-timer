## Изменения

- За цикл до возобновления трассы участники следующего выхода видят жёлтые треугольники подготовки. Значки этой паузы исчезают из строк участников. Работает в современном и Legacy-интерфейсах, включая удержание всей волны.
- Исправлено сохранение состояния установленного таймера: Windows MSI, macOS PKG и Linux DEB используют пользовательский каталог вместо каталога программы. В Windows это `%LOCALAPPDATA%\FDV Bouldering Timer\runtime-state`; запуск от администратора для сохранения больше не требуется.
- Portable-версии сохраняют состояние рядом с таймером. Старые установки без маркера и каталоги, закрытые для записи, автоматически используют пользовательский каталог. Старое сохранение импортируется, если нового ещё нет; выбранный путь показывается в журнале лаунчера.
- Обновлена документация по хранению и переносу состояния.

Сборка приложения: **393**. Установите обновление и перезапустите сервер для применения исправления.

## Downloads / English

- Preparation markers now appear one cycle before a paused route resumes, including the held upstream wave. Markers for that pause disappear from participant rows. Modern and Legacy displays share this behavior.
- Installed desktop packages save server state in a per-user directory. Portable packages retain local state storage, with a per-user fallback for read-only directories. Existing snapshots are imported when the new location has no snapshot.
- Installers: Windows MSI, macOS PKG for Intel and Apple Silicon, Linux DEB for x64 and ARM64.
- Portable archives include Node.js 24.17.0 LTS. A single-file standalone HTML timer is also available.
- The Android APK is a single-device standalone timer: it has no built-in server, LAN displays, or browser synchronization. It uses the existing release signing key and can update the previous APK.
- `SHA256SUMS.txt` lists checksums for all release files.
