## Изменения

- После завершения одноразового отсчёта на `00:00` таймер сразу использует настроенные цвета перерыва, не запуская отдельный перерыв. Обычный и Legacy-экраны переключают цвета на одной и той же границе времени.
- Пройденные трассы теперь обозначаются тёмно-синими ромбами, а красный цвет остаётся отличительным признаком полностью остановленной трассы.
- На портретных Legacy-экранах уменьшены колонки номера и трасс, чтобы оставить больше места ФИО. Если таблица всё же шире экрана, доступна горизонтальная прокрутка.
- Android APK учитывает фактический размер системных панелей и вырезов экрана на Android 15 и новее. Кнопки не перекрываются кнопочной или жестовой навигацией, а при скрытых панелях не остаётся постоянного пустого отступа.
- Исправлён macOS PKG: Installer больше не перенаправляет обновление в найденную старую portable-копию приложения. Установленная версия всегда обновляется в `/Applications/FDV Bouldering Timer`; release workflow проверяет это свойство перед публикацией.
- Обновлены руководство, архитектурная документация, тесты и иллюстрации.

Сборка приложения: **402**. Для применения исправлений установите обновление и перезапустите сервер.

## Файлы для установки

- Windows x64: MSI и portable ZIP.
- macOS: PKG и portable TAR.GZ для Intel (x64) и Apple Silicon (ARM64).
- Debian/Ubuntu Linux: DEB и portable TAR.GZ для x64 и ARM64.
- Android: подписанный APK **FDV Bouldering Timer**, только автономная версия для одного устройства — без встроенного сервера, сетевых экранов и синхронизации. Используется прежний ключ подписи для обновления приложения.
- Любая ОС с браузером: один автономный HTML-файл.

Desktop-пакеты включают Node.js 24.17.0 LTS, темы, шрифты, звуковые профили и руководство. Установленные версии используют пользовательский каталог состояния; portable-версии сохраняют состояние рядом с программой, с резервным пользовательским каталогом при запрете записи. `SHA256SUMS.txt` содержит контрольные суммы файлов релиза.

## Changes / English

- A completed one-shot timer at `00:00` immediately uses the configured break colors without starting a separate break. Modern and Legacy displays switch colors at the same time boundary.
- Completed routes now use dark-blue diamonds, leaving red as the distinct marker for a permanently stopped route.
- Portrait Legacy displays use narrower number and route columns to preserve more space for participant names. Horizontal scrolling remains available when a table is still wider than the screen.
- On Android 15 and newer, the APK respects the actual system-bar and display-cutout insets. Timer buttons remain clear of button or gesture navigation, without a fixed empty gap when bars are hidden.
- Fixed the macOS PKG so Installer cannot redirect an upgrade to an older portable app found elsewhere on disk. The installed copy is always updated under `/Applications/FDV Bouldering Timer`, and the release workflow verifies this before publishing.
- Updated the user guide, architecture documentation, tests, and screenshots. Application build: **402**. Restart the server after upgrading.

## Downloads / English

- Windows x64 MSI and portable ZIP; macOS Intel/Apple Silicon PKG and portable TAR.GZ; Debian/Ubuntu Linux x64/ARM64 DEB and portable TAR.GZ.
- Desktop packages include Node.js 24.17.0 LTS, themes, fonts, sound profiles, and the user guide. Installed packages use per-user state storage; portable packages retain local storage with a per-user fallback for read-only directories.
- The signed Android APK is a single-device standalone timer only: no built-in server, LAN displays, or browser synchronization. It uses the existing release signing key to update previous APKs.
- A single-file standalone HTML timer and `SHA256SUMS.txt` are also included.
