## Исправление старта Финала

Точечный выпуск на основе v2.3.0 (сборки 413), без новых функций ветки develop.

- Исправлен отсутствующий стартовый сигнал на дополнительных современных браузерах при ручном запуске Финала. Все клиенты с разрешённым и разблокированным звуком теперь планируют START по общей серверной отметке времени, а не только браузер, где нажали «Старт».
- Исправление действует и при восстановлении звукового расписания до начала попытки. Страховочный механизм оператора не дублирует уже запланированный сигнал.
- Предварительный отсчёт Финала по-прежнему заканчивается ожиданием ручного старта. Классика, Фестиваль, последние пять секунд и сигнал окончания не менялись.
- Добавлены проверки двух клиентов, повторной попытки, предварительного отсчёта и крайних поправок звука −750/+250 мс.

Сборка приложения: **437**. После установки перезапустите сервер и обновите все страницы таймера. На каждом звуковом устройстве проверьте разрешение звука и выполните тест сигналов.

Сообщение о полном отсутствии всех сигналов на отдельных устройствах расследуется отдельно; этот выпуск исправляет подтверждённую ошибку START и не заявляет решения пока не воспроизведённых причин полной тишины.

## Final start hotfix

This narrowly scoped release is based on v2.3.0 (build 413), without newer develop features.

- Fixed missing START on other modern browsers when an operator manually starts Final. Every client with sound enabled and unlocked now schedules START against the shared server timestamp, not only the browser where Start was pressed.
- The fix also covers audio-schedule restoration before the attempt starts. The operator watchdog does not duplicate the scheduled signal.
- Final's preliminary countdown still waits for manual Start. Classic, Festival, the final five warnings, and the end signal are unchanged.
- Added two-client regression coverage for repeated attempts, the preliminary countdown, and −750/+250 ms audio corrections.

Application build: **437**. Restart the server and reload every timer page after upgrading. Enable/unlock audio and test signals on each sound device.

Reports of all signals being silent on some devices remain a separate investigation; this release fixes the confirmed START defect, not unverified causes of complete silence.
