## Изменения

- Исправлена коррекция часов сервера: грубые показания `os.uptime()` больше не сдвигают ход таймера. На macOS используется монотонный источник времени, учитывающий сон системы; на других платформах восстановление после сна требует согласованного подтверждения. Изменение системных часов не меняет ход уже запущенного таймера.
- Плашка SYNC учитывает текущее состояние часов сервера: старое предупреждение не оставляет её красной навсегда. История событий остаётся доступна в диагностике.
- В основном таймере и автономной версии добавлена защита от краткого обратного переключения секунды или ротации при коррекции синхронизации до 100 мс. Защита влияет только на отображение: отсчёт, команды оператора и планирование звука используют исходное время.
- После остановки Финала кнопкой «Стоп» можно выбрать другой формат без возврата на первую ротацию. Переход требует подтверждения завершения Финала; отмена сохраняет его состояние. Во время работы и паузы переключение формата по-прежнему заблокировано.
- Исправлены сигналы окончания Финала: повторная попытка не теряет сигнал из-за предыдущей, а сообщение сервера о естественном завершении не отменяет уже запланированный звук. Ручная пауза и остановка отменяют ещё не начавшиеся сигналы. Добавлены проверки сценария «пауза → перемотка за 6 секунд до конца → продолжение».
- Обновлены руководство, документация синхронизации и диагностики, автономная версия и регрессионные тесты.

Сборка приложения: **409**. Для применения обновления перезапустите сервер после установки и обновите подключённые страницы таймера.

## Changes / English

- Fixed server clock correction: coarse `os.uptime()` readings no longer shift the timer. macOS uses a sleep-inclusive monotonic clock; other platforms require corroborating evidence before recovering elapsed time after sleep. Changing the system clock does not alter an already running timer.
- SYNC reflects current server clock health instead of remaining red because of a historical warning. Diagnostic history is preserved.
- The main timer and standalone version suppress brief backward second or rotation changes caused by synchronization corrections of up to 100 ms. This is a display-only guard: timing, operator commands, and audio scheduling continue using the original clock.
- After stopping a Final with the Stop button, switching formats no longer requires returning to rotation 1. A confirmation asks whether to end the Final; cancelling preserves its state. Format switching remains locked while running or paused.
- Fixed Final end signals: a previous attempt no longer suppresses the next attempt's signal, and a natural-completion server update no longer cancels already scheduled audio. Manual pause and stop cancel signals that have not started. Regression coverage includes pausing, seeking to six seconds before the end, and resuming.
- Updated the guide, synchronization and diagnostics documentation, standalone output, and regression tests.
