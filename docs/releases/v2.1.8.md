## Изменения

- На экранах со стартовыми списками показывается плашка «Ротация», в том числе в полноэкранном и Legacy-режимах. Без списков прежний вид сохраняется. «Цикл / Cycle» в интерфейсе и руководстве заменён на «Ротация / Rotation».
- Исправлено освобождение места после скрытия последнего списка на старых телевизорах в Legacy. Подгонка выполняется при изменении видимости списков, без нового постоянного пересчёта геометрии.
- Уточнены значки запланированных пауз: учитываются участники, которые должны лезть, и уже начавшие соревнование участники, которые должны готовиться к следующей трассе. Подготовка перед первой трассой не обозначается паузой. За ротацию до возобновления показывается подготовка.
- В надписи «по ротацию» теперь указан последний номер приостановленной ротации, а не номер возобновления.
- Исправлено взаимодействие нескольких запланированных пауз на разных трассах: завершение одной не отменяет другую, участники и задержки рассчитываются с учётом порядка событий.
- Полная остановка трассы до начала или в момент начала запланированной паузы исключает её из расчёта, не удаляя запись. После удаления остановки восстанавливаются начало и окончание паузы, включая совпадающую ротацию начала.
- Из Windows MSI удалены неработающий флажок «Запустить таймер после установки» и действие автозапуска. Выбор каталога и ярлыков сохранён; таймер запускается через «Пуск», ярлык или установленный EXE.
- Обновлены руководство, справочные файлы и иллюстрации.

Сборка приложения: **400**. Для применения серверных исправлений установите обновление и перезапустите сервер.

## Файлы для установки

- Windows x64: MSI и portable ZIP.
- macOS: PKG и portable TAR.GZ для Intel (x64) и Apple Silicon (ARM64).
- Debian/Ubuntu Linux: DEB и portable TAR.GZ для x64 и ARM64.
- Android: подписанный APK **FDV Bouldering Timer**, только автономная версия для одного устройства — без встроенного сервера, сетевых экранов и синхронизации. Используется прежний ключ подписи для обновления приложения.
- Любая ОС с браузером: один автономный HTML-файл.

Desktop-пакеты включают Node.js 24.17.0 LTS, темы, шрифты, звуковые профили и руководство. Установленные версии используют пользовательский каталог состояния; portable-версии сохраняют состояние рядом с программой, с резервным пользовательским каталогом при запрете записи. `SHA256SUMS.txt` содержит контрольные суммы файлов релиза.

## Changes / English

- Start-list displays now show a read-only Rotation badge, including fullscreen and Legacy. The interface and manual use Rotation instead of Cycle.
- Old Legacy TVs reclaim the timer area when the last list is hidden, with a one-shot fit and no new periodic geometry loop.
- Planned pauses mark held climbers and preparation for subsequent routes, not preparation before the first attempt. Preparation appears one rotation before resumption. Pause labels show the last paused rotation, not the resumption rotation.
- Multiple planned pauses on different routes are resolved in chronological order; ending one no longer cancels another or assigns the wrong participants.
- A permanent route stop at or before a planned pause suppresses its effects without deleting it. Removing the stop restores both pause boundaries, including when stop and pause start in the same rotation.
- Removed the non-working Windows MSI launch-after-install checkbox and action. Destination and shortcut options remain; launch the timer from the Start menu, a shortcut, or the installed EXE.
- Updated documentation and screenshots. Application build: **400**. Restart the server after upgrading.
