# 04. Актуальный план улучшений

## Уже выполнено

- монотонное продвижение серверного таймера и абсолютные якоря;
- атомарные снимки и восстановление активного/приостановленного состояния;
- версии и идентификаторы команд, безопасные повторы;
- SSE с периодическим восстановительным state-запросом;
- модульные и интеграционные тесты времени;
- автономное продолжение modern/Legacy и явный возврат к серверу;
- ревизии и компактная передача стартовых списков;
- вынесение list-render/width-fit из критического тика;
- диагностика сети, синхронизации, отрисовки, AudioContext, SSE, вкладки и часов сервера;
- визуальные сценарии телефонов, старого ТВ, часов, списков и перетаскивания прогресса.

## Следующий порядок

1. Снять воспроизводимый профиль на физическом старом телевизоре для четырёх максимальных списков.
2. Накопить диагностические записи реальных аномалий часов сервера и определить политику только по данным.
3. Расширить тесты восстановления после заморозки процесса/вкладки и длинной потери сети.
4. Постепенно дробить `index.html` на совместимые модули без изменения API и Legacy.
5. Добавить автоматическую проверку битых ссылок, отсутствующих изображений и запрещённых пользовательских терминов в документации.
6. Перед каждым релизом обновлять скриншоты справки из текущего браузера и выполнять полный визуальный прогон.

Новые оптимизации принимаются только с измерением. Уменьшение частоты корректного тика или отключение резервной синхронизации не являются допустимой заменой устранению конкретной дорогой операции.
